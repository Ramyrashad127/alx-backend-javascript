This repository covers modern backend JavaScript development completed as part of the **ALX Software Engineering Program**. It encompasses modern ECMAScript 6+ syntax and idioms, typed development with TypeScript, asynchronous workflows (Promises, Async/Await), Node.js core modules, HTTP/Express server architectures, and comprehensive unit and integration testing.

---

## Curriculum & Directory Structure

| Module Directory | Topic | Key Concepts & Technologies |
| :--- | :--- | :--- |
| [0x00-ES6_basic](./0x00-ES6_basic) | ES6 Basics | `let`/`const`, Arrow Functions, Template Literals, Rest/Spread, Iterators |
| [0x01-ES6_promise](./0x01-ES6_promise) | ES6 Promises | Promises, Chaining, `Promise.all`, `Promise.race`, `async`/`await`, Error Handling |
| [0x03-ES6_data_manipulation](./0x03-ES6_data_manipulation) | Data Manipulation | Typed Arrays, `Set`, `Map`, `WeakMap`, Array Methods (`map`, `filter`, `reduce`) |
| [0x04-TypeScript](./0x04-TypeScript) | TypeScript | Static Typing, Interfaces, Enums, Generics, Webpack Bundling, Ambient Declarations |
| [0x05-Node_JS_basic](./0x05-Node_JS_basic) | Node.js Fundamentals | CLI I/O (`stdin`), `fs` Sync/Async, Native HTTP Server, Express.js Server, CSV Parsing |
| [0x06-unittests_in_js](./0x06-unittests_in_js) | Unit Testing in JS | Mocha, Chai (`expect`, `should`), Sinon (Spies, Stubs, Mocks), Express API Testing |

## Environment & Tooling

- **Runtime**: Node.js `14.x`+ (Ubuntu 20.04 LTS recommended)
- **Package Manager**: `npm`
- **Linters & Formatters**: ESLint configured with custom rules (`.eslintrc.js`)
- **Transpilation & Bundling**: Babel (`@babel/preset-env`) & Webpack (`webpack`, `webpack-cli`)
- **Testing Frameworks**: Mocha, Chai, Sinon, Supertest

---

## Setup & Installation

Clone the repository and install dependencies at the root or within specific project directories:

```bash
git clone https://github.com/Ramyrashad127/alx-backend-javascript.git
cd alx-backend-javascript
npm install
```

To run test suites or scripts:
```bash
npm test
npm run dev
```
