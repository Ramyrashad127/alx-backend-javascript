# 0x00. ES6 Basics

## Description
This module introduces the modern features introduced in **ECMAScript 2015 (ES6)**, emphasizing readable, declarative, and bug-resistant JavaScript syntax.

## Learning Objectives
- Understanding variable scoping: `var` vs `let` vs `const`.
- Arrow functions and lexical `this` binding.
- Default function parameters and rest parameters (`...args`).
- Spread syntax for function calls, array literals, and object literals.
- Template literals with multi-line strings and expression interpolation.
- Object property shorthand and computed property names.
- Iterators and the `for...of` loop.
