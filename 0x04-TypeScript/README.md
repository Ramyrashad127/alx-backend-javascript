# 0x04. TypeScript

## Description
This directory covers **TypeScript** fundamentals, providing static typing, interface contracts, class hierarchies, and bundling with Webpack.

## Sub-tasks
- **task_0**: Student interface, DOM table generation with vanilla TypeScript.
- **task_1**: Teacher and Directors interfaces, printTeacher function type, class construction contract.
- **task_2**: Advanced types, Union types, Type Predicates (`isDirector`), String Literal types (`Subjects`).
- **task_3**: Ambient namespaces (`CRUD`), declaration files (`interface.ts`, `crud.d.ts`).
- **task_4**: Namespace architecture (`Subjects`), Cpp, React, and Java classes.
- **task_5**: Nominal typing and brand types (`MajorCredits`, `MinorCredits`).

## Build & Test
```bash
npm install
npm run build
```
