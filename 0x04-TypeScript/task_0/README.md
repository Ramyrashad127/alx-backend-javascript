# TypeScript - Task 0: DOM Manipulation & Interfaces

## Description
Defines a `Student` interface and renders a typed HTML table of students dynamically using Vanilla TypeScript.

## Interface Contract
```typescript
interface Student {
  firstName: string;
  lastName: string;
  age: number;
  location: string;
}
```

## Build & Run
```bash
npm install
npm run build
```
