# TypeScript - Task 1: Teacher & Director Contracts

## Description
Demonstrates interface inheritance, optional attributes, readonly properties, and constructor interface definitions.

## Key Concepts
- `Teacher` interface with dynamic additional properties `[key: string]: any;`.
- `Directors` interface extending `Teacher` with required `numberOfReports`.
- `printTeacherFunction` type definition.
- `StudentClass` constructor and method interfaces.
